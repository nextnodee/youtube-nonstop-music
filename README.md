# youtube-nonstop-music - version 1.0.0
**YouTube NonStop Music** is a browser extension that auto-dismisses the "Continue watching?" popup, keeping YouTube/YouTube Music playing without interruption. 

## Install

1. Download the repo (Code → Download ZIP, or `git clone`) and extract it.
2. Go to `chrome://extensions` (or `edge://extensions`).
3. Turn on **Developer mode**.
4. Click **Load unpacked** and select the extracted folder. 

## How to use
Just open YouTube or YouTube Music and play normally, it works automatically in the background. 

Click the extension icon in the toolbar to toggle its settings on/off.
